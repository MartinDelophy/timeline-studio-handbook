## 添加新 session

复制 [`_template`](_template/README.zh-CN.md) 到下一个编号目录。用户创作 brief 应原样保留，但只公开安全的 session 上下文。禁止公开隐藏推理、密钥、凭据、私有媒体路径或个人信息。

制作提示词可以由 Skill 在执行过程中生成，也可以在完成后根据显式决策整理。必须清楚标注来源，不能把衍生提示词冒充为用户原话。
