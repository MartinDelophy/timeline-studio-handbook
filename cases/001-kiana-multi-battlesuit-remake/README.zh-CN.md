## 用户原始意图

用户希望测试 `edit-timeline-studio`：基于本地参考视频，用网上检索到的琪亚娜素材高度复刻画面位置和剪辑玩法。执行过程中，用户明确了四项硬约束：

- 保留原音轨；
- 保持 720×1280 竖屏容器，并让横画面整体侧躺；
- 使用多套琪亚娜装甲，而不是只剪一条 PV；
- 正式镜头只能使用高清 CG 感素材，不能使用低清或带游戏 UI 的画面。

最初请求和关键澄清原文收录在[原始需求](prompts/00-original-brief.md)中。

## 展示的 Skill 能力

### 1. 参考视频分析

Skill 将参考片识别为“逐词文字、重复角色镜头、黑场断句、闪白/模糊冲击、后半段密集高潮”组成的短视频模板，并确认特殊观看方式是：竖屏文件中放置整体旋转的横版画面，最后尾卡恢复正向。

### 2. 带约束的网络素材检索

执行过程没有把“网上能看”等同于“可以下载复用”。平台离线下载、低清 GIF、带 HUD 的实机画面和第三方下载绕过方案都被拒绝。检索随后转向米哈游第一方媒体和官方社区 Wiki 暴露的原始文件，在剪辑前记录清晰度、来源与镜头适配度。

### 3. 镜头功能映射

不同 PV 没有被简单首尾拼接，而是按照戏剧功能和参考片节拍分配：

```text
空之律者 → 天穹游侠 / 流星阶段 →
薪炎之律者 → 咚！炽愿吉星
```

装甲切换落在黑卡、白闪、结构转折和高潮上，而不是源视频的任意边界。

### 4. 反馈驱动的视觉 QA

用户发现了单纯媒体参数检查无法识别的问题。Skill 在不改变总时长的前提下定位并修正：

| 版本 | 用户反馈 | 修改 |
| --- | --- | --- |
| v2.1 | 16.20–17.07 秒出现德丽莎 | 将整段 26 帧替换成琪亚娜单人近景 |
| v2.2 | 开头也出现德丽莎 | 替换开头 34 帧，并裁除素材自带字幕区域 |
| v2.3 | 后面两次人物立绘重复 | 保留第一次立绘，只把后两次替换为不同琪亚娜 3D 镜头 |
| v2.4 | 14.00–14.87 秒仍有德丽莎 | 再替换 26 帧为空之律者单人镜头 |

### 5. 技术验收

源成片完成解码检查，并与硬约束对照：

| 帧率 | 30 fps |

## 迭代得到的经验

- 结构相似并不代表人物身份正确；角色级 QA 需要接触表和目标时间段抽帧。
- “使用多套皮肤”是一项叙事约束，不是简单拼接多条视频。
- 参考片中的重复镜头需要保留时，每次重复都应承担提醒、升级、对比或高潮功能。
- 明确的技术硬约束让局部修改更安全：每次修正都维持 794 帧、26.466667 秒和原音频时钟。

## `.timeline` 工程佐证

案例提供可移植的 [`.timeline` 工程包](assets/kiana-multi-battlesuit-remake.timeline)，内部包含 `project.json`、归档媒体、session ID、媒体 SHA-256、794 帧证据，以及总计 26.466667 秒的 27 个可编辑节拍片段。

历史 session 没有保留当时的原始多源工程，因此这个佐证文件被准确标注为**根据最终 master 重建的归档切点时间线**。它可以证明 Timeline Studio 工程结构和节拍级可编辑分段，但不会冒充已经遗失的原始素材裁切工程。后续案例应在制作时直接保存原生多源 `.timeline`。
