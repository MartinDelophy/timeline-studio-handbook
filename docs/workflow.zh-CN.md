# 我的 Timeline Studio 工作流

这套流程适合短视频、产品演示、教程和素材混剪。它强调先做内容决策，再让自动化承担重复劳动。

## 1. 定义交付目标

开始导入素材前，先写下：

- 发布平台与画面比例；
- 受众与希望观众完成的动作；
- 目标时长和信息密度；
- 必须出现的镜头、文字或品牌元素；
- 截止时间与质量边界。

建议用一句话描述任务：

> 将【素材】剪成一条面向【受众】的【时长/比例】视频，让观众理解【核心信息】并完成【行动】。

## 2. 整理素材

导入前先按用途整理，而不是按文件来源堆放：

```text
project-name/
├── footage/       # 主镜头与补充镜头
├── audio/         # 人声、音乐、音效
├── graphics/      # Logo、截图、插画
├── references/    # 风格与节奏参考
└── exports/       # 导出结果
```

同时确认素材授权、分辨率、帧率、音频质量和是否包含敏感信息。

## 3. 先搭叙事，再做细节

先用标记或文字建立内容骨架：开场钩子、背景、核心信息、证据/演示、结尾行动。粗剪阶段只判断“这段是否服务目标”，暂时不花时间调整单帧和复杂特效。

## 4. 使用 AI 辅助粗剪

适合交给 AI 的任务包括：

- 转录、摘要和内容分段；
- 识别停顿、重复表达和候选高光；
- 根据目标时长提出删减方案；
- 生成字幕初稿和多平台版本建议；
- 对已有时间线提出结构性修改建议。

提示词尽量包含目标、约束和不得修改的内容。例如：

```text
请把这段访谈整理为 60 秒竖屏短视频。保留产品演示和最终结论，删除重复表达与长停顿；
开头 3 秒先给出结果。不要改写说话人的原意，无法确认的专有名词请标记出来。
```

AI 输出应视为粗稿。涉及事实、人物表达、品牌规范和版权的部分必须人工检查。

## 5. 人工精修

按以下顺序处理，减少返工：

1. 叙事：信息是否完整，开场是否足够快，结尾是否明确。
2. 节奏：删除无意义停顿，给重点留出呼吸空间。
3. 画面：构图、裁切、转场和补充镜头是否服务内容。
4. 声音：人声可懂度、音乐层级、响度和突变。
5. 字幕：断句、专有名词、遮挡和安全区。
6. 视觉统一：字体、颜色、动画速度和品牌元素。

## 6. 导出前检查

- 从头到尾完整播放一次，不拖动时间线。
- 静音观看一次，确认字幕和画面仍可理解。
- 只听声音一次，检查断音、噪声与音量跳变。
- 检查首帧、尾帧、拼写、链接和行动号召。
- 在目标设备或平台预览，确认比例、清晰度和安全区。
- 保留一个高质量母版，再生成平台版本。

## 7. 复盘并记录

每次完成后记录：总耗时、AI 节省的步骤、返工最多的步骤、观众反馈/数据，以及下次要保留或改变的做法。建议使用[案例模板](../cases/_template/README.zh-CN.md)归档 session、提示词、过程和结果。

## 工作流原则

- 自动化越多，验收标准越要明确。
- 同一个项目只保留一个“当前正确”的主时间线。
- 先解决内容问题，再解决视觉问题。
- 参数只是上下文，效果与可复现性才是结论。
