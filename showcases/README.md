# Showcases

This directory collects real projects completed with Timeline Studio. A showcase is about more than the final video: it should preserve the method, key decisions, and reproducible context.

## Acceptance criteria

A showcase should:

- have a clear relationship to Timeline Studio;
- include a preview, or anonymized screenshots when the final video cannot be public;
- explain the goal, source material, key steps, and export settings;
- distinguish AI-assisted work from human adjustments;
- disclose asset sources and usage rights;
- contain no secrets, personal data, or unauthorized commercial material.

## Add a case

Copy `_template` to a short kebab-case directory name:

```text
showcases/product-demo-short/
├── README.md
└── assets/
    ├── cover.jpg
    └── preview.gif
```

Complete the [case template](_template/README.md), add a row to the index above, and follow the [contribution guide](../CONTRIBUTING.md).

Keep the repository lightweight by compressing images. Host large videos externally on a stable service and record their duration, resolution, and file size in the case.
